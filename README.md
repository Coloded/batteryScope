# BatteryScope

[Скачать последнюю версию для Apple Silicon и Intel](https://github.com/Coloded/batteryScope/releases/latest) · [Обновления и выпуск релизов](docs/UPDATES.md)

Личное нативное приложение для macOS, вдохновлённое функциональностью coconutBattery. Собственная реализация и интерфейс. Приложение запускается **только на Mac**, но читает подключённые Apple-устройства. Поддержка и ограничения описаны в [ТЗ](docs/SPEC.md).

## Запуск

Нужны macOS 13+ и Apple Command Line Tools (Swift 5.9+). Sparkle 2.9.6 загружается с официального GitHub и проверяется по SHA-256; framework встраивается в приложение. Для iPhone/iPad установите `brew install libimobiledevice`; батарея Mac и Bluetooth-аксессуары работают без этой зависимости.

```sh
bash scripts/build.sh
open "${TMPDIR:-/tmp}/batteryscope-build/BatteryScope.app"
```

Готовое приложение собирается во временной папке macOS; точный путь выводит скрипт. Для установочного DMG запустите `bash scripts/prepare-release.sh` на Mac с ключом подписи. Локальная ad-hoc подпись; это сборка для личного использования, без нотарификации Apple. Сборка универсальная: Apple Silicon (`arm64`) и Intel (`x86_64`).

## Что работает

- iPhone, iPad и iPod touch через USB/доверенное Wi-Fi-соединение: заряд и доступная диагностика.
- Magic Keyboard/Mouse/Trackpad: заряд через macOS. AirPods: доступные уровни наушников/футляра.
- Отключённые Bluetooth-аксессуары отмечены как кэш macOS; их данные не сохраняются и не вызывают уведомлений.
- Раздельная история устройств и доступ к архиву после отключения.

- Реальное чтение батареи Mac через IOKit; заряд, ёмкость, износ, циклы, температура, напряжение, ток и мощность при наличии данных.
- Снимки вручную и автоматически раз в час, пока приложение работает; график состояния, статистика сохранённых наблюдений.
- Строка меню, уведомления по заряду/оставшемуся времени, CSV, настраиваемый HTML-отчёт и системная печать/PDF.
- Исходные поля батареи и системные сведения о накопителях.

На настольном Mac батарея отсутствует: приложение показывает явное сообщение и прочерки. Показатели не подменяются демонстрационными значениями. Набор диагностических полей зависит от оборудования и macOS. Системная оценка оставшегося времени может быть недоступна; некоторые SSD не раскрывают статистику чтения/записи.

База SQLite: `~/Library/Application Support/BatteryScope/BatteryScope.sqlite`. Таблицы `devices`, `samples`, `technical`, `metadata`; режим WAL. История из старого `history.json` переносится один раз транзакционно, сам JSON сохраняется как резервная копия. Настройки — в UserDefaults домена приложения. Телеметрии и серверной части нет. Исходные сведения могут содержать серийные номера; экспорт выполняется только по действию пользователя.

## Проверка

```sh
bash scripts/test.sh
```

Тесты проверяют единицы ёмкости Intel/Apple Silicon, знаковый ток, пропущенные значения, сериализацию истории, экранирование экспортов и чтение текущего Mac. Для проверки физических датчиков, разрядки и уведомлений по порогам нужен MacBook.

## Границы совместимости

Проверены подключённый iPhone, Magic Keyboard и Magic Trackpad. Один телефон, видимый по USB и Wi-Fi, отображается один раз с приоритетом USB. Wi-Fi использует ранее установленное доверие и настройку Finder. Для полноценной проверки Wi-Fi нужно отключить USB.

Apple Watch, Pencil, AirTag, HomePod и другие Mac не имеют реализованного удалённого источника батареи. Apple TV может быть обнаружен libimobiledevice при поддерживаемом доверенном соединении; физическая совместимость не проверена, встроенной батареи у него нет. Поддержка iPad, iPod touch и подключённых AirPods требует аппаратной проверки.

`bash scripts/test.sh --live-devices` дополнительно проверяет реально подключённый iPhone и читает аксессуары; запускать вне ограничивающей USB-сервис песочницы.

## Установка и верхняя панель

Версия 0.3.0 установлена в `/Applications/BatteryScope.app`. Встроена собственная иконка `Assets/AppIcon.icns`; исходник `Assets/AppIcon.png`, описание генерации `Assets/ICON.md`.

Приложение содержит постоянный MenuBarExtra со значком батареи и зарядом. Закрытие главного окна не завершает приложение. Из меню можно открыть окно, обновить показания или явно завершить процесс. Позицию значка относительно часов определяет macOS. Автозапуск при входе в систему сейчас не настраивается.

## Характеристики

Раздел «Характеристики» читает подробный снимок по запросу: аппаратная платформа, ОС, прошивки, накопитель; на Mac также память, дисплеи, USB, Thunderbolt, аудио и питание. Есть поиск по имени/значению и экспорт JSON. Последний снимок каждого устройства хранится в SQLite и доступен после перезапуска. Дата снимка явно показана; для обновления нажмите «Прочитать заново».

Не все Apple-устройства раскрывают все паспортные характеристики. Отсутствующие RAM/экран/камера не подменяются догадками. Из корневых свойств iPhone исключены номера телефона, данные SIM/абонента и служебные ключи; аппаратные идентификаторы остаются в характеристиках.

## Обновления 0.4.0+

Используется официальный Sparkle 2, как в Video_editor: автоматическая проверка, стандартный диалог установки и подпись обновлений Ed25519. Команда «Проверить обновления…» доступна в меню приложения, верхней панели и настройках. Исходники и подписанные DMG публикуются в [Coloded/batteryScope](https://github.com/Coloded/batteryScope).

Приватный ключ остаётся в Keychain на компьютере, выпускающем релиз; GitHub Actions проверяет и публикует готовые подписанные файлы. Пользовательская SQLite-база не входит в пакет приложения и не заменяется при обновлении. Подробная инструкция — [docs/UPDATES.md](docs/UPDATES.md).
