# BatteryScope 0.4.0

- Официальный механизм обновлений Sparkle 2, как в Video Editor.
- Проверка обновлений в меню приложения, верхней панели и настройках.
- Универсальное приложение для Apple Silicon и Intel, macOS 13 или новее.
- Батареи Mac, iPhone/iPad и доступные Apple-аксессуары; история в SQLite.
- Технические характеристики устройств с поиском и экспортом.

Версии 0.3.x и ниже устанавливаются поверх вручную один раз: в них ещё нет Sparkle. После установки 0.4.0 следующие версии можно получать из приложения. Для диагностики iPhone/iPad на другом Mac требуется `brew install libimobiledevice`; версия Homebrew должна соответствовать архитектуре Mac.
