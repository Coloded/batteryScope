# BatteryScope 0.7.0

- Компактный обзор с показателями, подходящими выбранному устройству. На настольных Mac — мощность, конфигурация и ядра CPU/GPU, когда система предоставляет их количество.
- Единый обзор для локальных и облачных Mac с датой снимка. Новые снимки передают краткую конфигурацию; для этого обновите приложение на каждом Mac.
- Аналитика и история по доступным измерениям: мощность Mac, заряд аксессуаров, отдельные наушники и кейс. Пустые показатели скрыты.
- Характеристики в компактной таблице со сворачиваемыми разделами. Питание аксессуаров отделено от служебных событий драйвера.
- Исправлено обновление характеристик Bluetooth-аксессуаров. Сохранённые показания macOS явно обозначены.
- Предупреждения о снижении ёмкости аккумулятора и подтверждённых статусах обслуживания macOS. Недоступные данные не трактуются как исправность; низкий заряд не считается износом.
- Сохранены автоматический опрос при бодрствовании и пауза работы во время сна.

История SQLite сохраняется. Установщик не содержит личных данных. Apple Silicon и Intel, macOS 13+.
