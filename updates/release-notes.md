# BatteryScope 0.5.1

- Встроены libimobiledevice и зависимости для Intel и Apple Silicon. Для iPhone/iPad больше не нужно устанавливать Homebrew или вводить команды в Терминал.
- Разблокируйте подключённый iPhone/iPad и подтвердите доверие к Mac.

- Общая история между Mac через выбранную папку iCloud Drive: отдельные идентификаторы Mac, объединение без повторных UUID, локальная SQLite, архивные устройства в боковой панели и общий CSV. По умолчанию выключено. На обоих Mac выберите одну и ту же папку iCloud Drive в настройках. Обмен между тестовыми базами проверен; реальная доставка iCloud на двух Mac ещё требует проверки.

- Русские названия и пояснения технических характеристик в разделах «Характеристики» и «Подробности».
- Поиск по русскому названию, оригинальному коду, пояснению и значению.
- Объём накопителя показан в ГБ/МБ, известные логические признаки — «Да»/«Нет»; исходные значения сохранены рядом.
- В JSON-экспорт добавлены переводы без изменения исходных полей.
- Недокументированные служебные параметры Apple явно отмечены; неоднозначные единицы и коды не интерпретируются.

Универсальная сборка для Apple Silicon и Intel, macOS 13+.

Обновление сохраняет существующую локальную историю. Установщик не содержит личных данных.
