# Выбор устройства в 0.6.0

Левый список заменён меню с выбранным устройством, типом подключения и текущим зарядом. В меню доступны подключённые и архивные устройства; выбранное отмечено галочкой. При выборе сохраняется текущий раздел приложения. Архивный процент не выдаётся за текущий заряд.

Для устройств нарисованы 14 векторных шаблонных иконок: настольный Mac, ноутбук, телефон, планшет, клавиатура, трекпад, мышь, вкладыши, полноразмерные наушники, часы, ТВ, колонка, плеер и общее устройство. Они используются в выборе устройства и панели приложения возле часов. Наличие иконки не означает поддержку чтения соответствующего устройства.

Иконки создаются локально кодом AppKit, не зависят от новых SF Symbols; цвет задаёт система. При неизвестном типе используется общая иконка. Сборки обеих архитектур прошли; меню, стрелка раскрытия и иконка ноутбука проверены визуально в установленном приложении. Автоматическая интерактивная проверка ограничена ошибкой службы управления UI.
