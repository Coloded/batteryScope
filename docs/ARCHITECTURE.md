# Архитектура BatteryScope

Код сгруппирован по назначению. Файл представляет связный компонент или экран, а не отдельную функцию. Swift Package автоматически включает подпапки; скрипт тестов перечисляет только необходимые для тестов компоненты.

| Каталог | Ответственность и место изменений |
|---|---|
| App | Запуск приложения, корневой экран, наблюдаемое состояние и координация сервисов |
| Domain | Codable-модели батареи и мощности; совместимость сохранённых снимков |
| Devices | Чтение Mac и подключённых устройств, разбор ответов, расширенные характеристики |
| History | SQLite, формат обмена, папка iCloud и подтверждения от других Mac |
| Platform | События питания, сведения CPU/GPU, автозапуск, локальная диагностика, Sparkle |
| Reports | CSV/HTML/JSON и системные действия экспорта/печати |
| Infrastructure | Запуск внешних утилит с тайм-аутом и поиск встроенных зависимостей |
| UI/Overview | Обзор батареи, отдельные показатели и график мощности |
| UI/History | История и аналитика сохранённых наблюдений |
| UI/Devices | Подробности и технические характеристики |
| UI/Settings | Настройки подключения, iCloud, автозапуска и диагностики |
| UI/MenuBar | Окно возле часов |
| UI/Shared | Общие элементы интерфейса, меню устройств, векторные иконки, русские подписи |

Store — MainActor-координатор и единое наблюдаемое состояние. Действия истории, экспорта и характеристик вынесены в тематические extensions рядом с соответствующими сервисами. SQLite используется на MainActor; медленный ввод-вывод устройств и файлов синхронизации — в utility-задачах. События питания вызывают только чтение Mac. Опрашивать USB/Bluetooth каждые пять секунд запрещено.

Публичные форматы не зависят от UI. Новые поля снимков optional, чтобы сохранялась совместимость с прежней SQLite и JSON. Значения мощности имеют разные имена и не подменяются друг другом. Для неизвестных показателей используется nil.

Перед выпуском: scripts/test.sh, scripts/build.sh, scripts/prepare-release.sh; проверка приватности, соответствия исходников, библиотек обеих архитектур, подписей и доступности установщика до переключения appcast.
