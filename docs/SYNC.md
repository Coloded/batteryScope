# Общая история BatteryScope через iCloud Drive

Статус: собрано и установлено локально в версии 0.5.0 (6). Тест обмена между двумя временными SQLite прошёл. Реальная доставка через iCloud между двумя Mac ещё не проверена. Для обмена нужна версия 0.5.0 или новее на каждом Mac. В 0.4.0 этой функции нет.

## Настройка после выпуска

1. Установить новую версию BatteryScope на каждый Mac, включить iCloud Drive под одной учётной записью Apple.
2. Создать в iCloud Drive папку для истории. В BatteryScope → Настройки → «Общая история · iCloud Drive» выбрать эту же папку на каждом Mac. Выбор включает обмен. Для локальной папки автоматической доставки на другие компьютеры не будет.
3. Оставлять BatteryScope работающим для новых измерений. Обмен запускается после опроса устройств не чаще раза в пять минут; можно нажать «Обменяться сейчас». Файлы между Mac доставляет macOS, без гарантии немедленного появления.
4. В боковой панели выбрать нужное устройство. На странице истории раскрыть общий список; экспорт CSV содержит всю историю и компьютер-источник. Архивные устройства имеют дату последнего измерения.

В Finder рекомендуется «Сохранять загруженным» для общей папки, если команда доступна. При выгрузке файлов приложение запрашивает загрузку через системный API и повторяет чтение при следующем обмене. Работа с реально выгруженными файлами iCloud требует проверки на двух Mac.

## Хранение и объединение

SQLite остаётся по адресу `~/Library/Application Support/BatteryScope/BatteryScope.sqlite` на каждом Mac. Живой файл базы и WAL в iCloud не копируются. В выбранной папке создаётся `BatteryScope-History-v1`, по одному неизменяемому JSON-файлу на UUID снимка. Доступ координируется через NSFileCoordinator. Входящие снимки объединяются транзакционно; уже существующие UUID пропускаются. Повреждённые и неизвестные форматы отображаются в статусе, не заменяя сохранённую историю.

У каждого Mac отдельный идентификатор на основе SHA-256 аппаратного UUID; если UUID недоступен, используется локально сохранённый случайный идентификатор. Локальное старое имя `mac` преобразуется только при обмене, без переноса существующей базы. У iPhone/iPad и Bluetooth сохраняются идентификаторы устройств, поэтому история одного устройства объединяется при подключении к разным Mac. Источник каждого измерения сохраняется.

Передаются имена устройств и Mac, идентификаторы (в том числе UDID телефонов и адреса Bluetooth), модели, время измерения и доступные показатели батареи. Диагностические словари, отдельная таблица технических характеристик и настройки приложения не передаются. Это личная папка пользователя, а не публичная публикация. iCloud занимается транспортом и хранением файлов; дополнительного сервера BatteryScope нет.

Выключение обмена сохраняет локальную историю и облачные файлы. Функции синхронного удаления истории пока нет: удалённый вручную файл может быть восстановлен другим Mac из его базы. При смене папки имеющаяся локальная объединённая история будет записана и туда. Это следует учитывать при выборе новой папки.

## Границы функции

Это общая история на **Mac с BatteryScope**. Apple Account и нахождение в одной сети сами по себе не открывают доступ к батарее другого Mac. Во сне или при закрытом приложении новых измерений нет. Настольные Mac тоже сохраняют снимки для общего списка, но показатели отсутствующей батареи остаются пустыми. История подключённых iPhone/iPad и аксессуаров также переносится между Mac; отдельного приложения просмотра на iPhone/iPad пока нет. Полные технические характеристики остаются на Mac, который их прочитал.

## Если обмен показывает нули

Нули обозначают отсутствие новых файлов/снимков за конкретный запуск, а не отсутствие сохранённой истории и не успешную доставку на другой Mac. Одинаковый локальный путь «Документы» на двух компьютерах не подтверждает общую папку iCloud.

Для 0.5.1: в Finder открыть именно iCloud Drive, создать там папку BatteryScope и дождаться её появления на другом Mac. В BatteryScope на обоих Mac выбрать эту же папку и нажать «Обменяться сейчас». Проверить, что созданная приложением вложенная папка BatteryScope-History-v1 и её файлы видны в Finder на обоих Mac. Если их нет, сначала проверить доставку iCloud. Не удалять текущую SQLite или прежнюю папку истории.

В исходниках для следующей сборки добавлены количество файлов в папке, проверка системного признака iCloud, ожидание отправки и ошибки iCloud. При отсутствии подтверждения больше не показывается безусловное утверждение, что доставкой управляет iCloud. Не собраны и не установлены по указанию пользователя.
