# Подготовка изображений для инструкции

На macOS скрипт использует системный ImageIO; нужен Swift из Command Line Tools. Установка сторонних библиотек не требуется. HEIC, PNG и JPEG преобразуются в PNG с учётом ориентации. Исходник и существующий выходной файл не перезаписываются; EXIF/GPS-метаданные не копируются.

Конвертация:

```sh
swift scripts/prepare-screenshot.swift screenshot/photo.heic /tmp/photo.png
```

Конвертация с обрезкой (X, Y, ширина, высота в пикселях; начало сверху слева после поворота):

```sh
swift scripts/prepare-screenshot.swift screenshot/photo.heic /tmp/photo-cropped.png --crop 100 200 1200 800
```

Применяется и к исходным PNG. Координаты за границами изображения отклоняются. Для повторного запуска выберите новое имя результата.

Личные исходники лежат в `screenshot/`, координаты пяти подготовленных изображений — в `screenshot/crops.json`. Иллюстрированная инструкция находится в `docs/private-guide/index.html` и `docs/private-guide/README.md`; обе папки с личными изображениями исключены из Git. Откройте HTML в браузере и нажмите на изображение для просмотра в полном размере.

Публикуемая по просьбе пользователя инструкция: [docs/guide/README.md](guide/README.md). В неё включены только пять выбранных обработанных иллюстраций; исходные фотографии остаются локально.
