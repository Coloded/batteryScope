# Проверка сборки 0.4.0

8 сентября 2026. Официальные обновления Sparkle 2.9.6.

- Обе архитектуры приложения собраны локально: arm64 и x86_64. Встроенный Sparkle также universal.
- 20 тестов приложения прошли.
- Созданы универсальный и stable DMG с одинаковыми байтами.
- validate-release.py подтвердил совпадение исходников и бандла, версии/номера сборки, feed URL, открытого ключа, архитектур и подписи кода.
- Ed25519-подпись DMG проверена независимо через CryptoKit. Изменение одного байта архива приводит к отклонению подписи.
- Приватный ключ хранится в Keychain под отдельной учётной записью BatteryScope, в git его нет.
- Основной runtime проверяется на Apple Silicon. Исполнение на физическом Intel Mac и полный цикл установки будущей версии поверх текущей ещё требуют проверки; наличие обеих Mach-O-архитектур проверено.

# Проверка сборки 0.2.0

8 сентября 2026. Приложение для macOS с подключёнными Apple-устройствами.

- Release-сборка и проверка подписи успешны.
- 16 тестов прошли: добавлены мобильные ответы, частичная диагностика, AirPods-кэш, сопоставление HID-адресов, экспорт компонентов и совместимость старой истории.
- Интеграционная проверка мобильного устройства прошла. Личные показания батареи не публикуются.
- Одно устройство, обнаруженное по USB и сети, отображается один раз с приоритетом USB. Сетевой запрос проверен; физическое отключение USB отдельно не проверялось.
- Проверены подключённые Bluetooth-аксессуары. Заряд отключённых аксессуаров не подставляется.
- Интерфейс устройства и сохранение истории проверены. Кэш отключённых аксессуаров не записывается.
- iPad/iPod touch, подключённые AirPods, Apple TV и потеря соединения требуют отдельной физической проверки. Приложение не заявляет поддержку Apple Watch, Pencil, AirTag, HomePod или удалённых Mac.

# Проверка сборки 0.1.0

8 сентября 2026, Apple Silicon, настольный Mac без встроенной батареи.

- `bash scripts/test.sh`: 10 тестов прошли. Набор не требует XCTest или полного Xcode.
- `bash scripts/build.sh`: release-сборка успешна, `.app` сформировано.
- `codesign --verify --deep --strict dist/BatteryScope.app`: успешно.
- `plutil -lint dist/BatteryScope.app/Contents/Info.plist`: успешно.
- Приложение запущено через LaunchServices, основное окно проверено визуально и через accessibility.
- Живой IOKit сообщает `BatteryInstalled = false`; интерфейс показывает отсутствие встроенной батареи и запрещает сохранение пустого снимка.
- Переходы в подробности и настройки работают. Асинхронно получены реальные сведения NVMe: модель, ёмкость, TRIM и SMART.
- Системный диалог печати открывается, одностраничный предпросмотр отчёта проверен визуально; печать отменена без отправки на принтер.

Ограничения проверки: на настольном Mac нельзя подтвердить физические показания MacBook, зарядку/разрядку, смену циклов или реальное срабатывание уведомлений по уровню батареи. Экспортные форматы проверены тестами; сохранение через системные диалоги и многостраничная печать требуют отдельной ручной проверки. iPhone/iPad не включены в текущую версию.

Сборка подписывается в системной временной папке перед копированием на внешний диск: это исключает служебные AppleDouble-файлы внешнего тома из этапа подписи. `--disable-sandbox` в скрипте относится только к вложенной песочнице SwiftPM для локального манифеста без внешних зависимостей.
