# Сборка 0.6.0 (8)

GitHub Actions run 34248480774 завершился успешно. Все три опубликованных файла сверены по размеру и SHA-256 с локальными артефактами.

- DMG 0.6.0 прошёл проверку манифеста исходников, кода, Ed25519 и отклонения изменённого файла; личной базы и истории нет.
- 32 теста прошли: мощности без подмены источников, реальный ноль, некорректный ток, сохранение новых полей SQLite, подтверждения участников обмена и имена iCloud placeholders.
- Production-сборки arm64 и x86_64 прошли; встроенные утилиты и библиотеки универсальны, подписаны и не требуют Homebrew.
- OpenSSL 4.0.2 собран для обеих архитектур. Встроенные утилиты успешно прочитали подключённый телефон; личные значения не записаны в отчёт.
- Приложение установлено в /Applications, прежняя копия сохранена отдельно. История SQLite не удалялась. Основное окно и наличие меню выбора устройства проверены через accessibility. Автоматическая интерактивная проверка меню ограничена ошибкой службы управления UI.
- Реальная стандартная папка распознана системой как iCloud. Созданные снимки получили от macOS признак ubiquitousItemIsUploaded=true. На первой попытке macOS временно сообщала ошибку доступа к iCloud; последующая проверка подтвердила отправку всех файлов.
- Получение на втором физическом Mac ещё не подтверждено: в папке пока один участник. Тест обмена двух синтетических SQLite прошёл.
- Intel проверен через сборку и Rosetta, а не отдельный физический Mac. Доставка MetricKit и автозапуск после входа не проверялись; функции выключены по умолчанию.

# Проверка сборки 0.1.0

8 сентября 2026, Apple Silicon, настольный Mac без встроенной батареи.

- `bash scripts/test.sh`: 10 тестов прошли. Набор не требует XCTest или полного Xcode.
- `bash scripts/build.sh`: release-сборка успешна, `.app` сформировано.
- `codesign --verify --deep --strict dist/BatteryScope.app`: успешно.
- `plutil -lint dist/BatteryScope.app/Contents/Info.plist`: успешно.
- Приложение запущено через LaunchServices, основное окно проверено визуально и через accessibility.
- Живой IOKit сообщает `BatteryInstalled = false`; интерфейс показывает отсутствие встроенной батареи и запрещает сохранение пустого снимка.
- Переходы в подробности и настройки работают. Асинхронно получены реальные сведения NVMe: модель, ёмкость, TRIM и SMART.
- Системный диалог печати открывается, одностраничный предпросмотр отчёта проверен визуально; печать отменена без отправки на принтер.

Ограничения проверки: на настольном Mac нельзя подтвердить физические показания MacBook, зарядку/разрядку, смену циклов или реальное срабатывание уведомлений по уровню батареи. Экспортные форматы проверены тестами; сохранение через системные диалоги и многостраничная печать требуют отдельной ручной проверки. iPhone/iPad не включены в текущую версию.

Сборка подписывается в системной временной папке перед копированием на внешний диск: это исключает служебные AppleDouble-файлы внешнего тома из этапа подписи. `--disable-sandbox` в скрипте относится только к вложенной песочнице SwiftPM для локального манифеста без внешних зависимостей.

## Невыпущенная синхронизация истории

Добавлены три теста исходников: идентичность Mac и сохранение источника при пересылке, отказ от неизвестной версии формата, обмен между двумя SQLite с повторным импортом и повреждённым файлом. Изначально запуск был отложен по запрету пользователя; после разрешения на сборку все 27 сценариев прошли (см. проверку 0.5.0 выше).

После разрешения на сборку проверить компиляцию на обеих архитектурах, выбор/повторное открытие security-scoped bookmark, обмен в обе стороны на двух реальных Mac через iCloud Drive, одновременную запись, отключение сети, выгруженные файлы iCloud, переключение папки во время обмена и выключение синхронизации. Проверить, что исходная SQLite остаётся доступной и архивные измерения не вызывают уведомлений о текущем заряде.
